# 文件系统规划(草案,随实现迭代)

原则:**所有状态都在文件系统里**——纯文件、可 ls、可 git、可 rm 重来,没有数据库没有隐藏状态。
agent 无记忆,进来先看目录就知道世界现状;`drawtell ls`(待实现)只是把这套目录读给你看。

## 两个根:工具 与 工作区

| | 位置 | 内容 | 公私 |
|---|---|---|---|
| 工具 | drawtell 检出/安装目录 | 代码、`dist/web`(播放页构建产物)、`scenes/`(种子场景 = 示例 + 打磨台内置 + 测试夹具) | 公开仓 |
| 工作区 | 运行 drawtell 命令的 cwd | 家庭内容与状态(下详) | 私有,建议独立 git 仓 |

CLI 约定:静态资源永远取自工具侧;`scenes/`、`bundles/`、`snaps/` 永远相对 cwd
(`--out`、`--bundles` 可改)。现有实现已符合,种子场景在工具仓里"自己当自己的工作区"。
家庭真题**不进公开的 drawtell 仓**,放私有工作区(第一道真题落地时建仓)。

## 工作区布局

```
<workspace>/
├── scenes/                 源:场景 TS —— 唯一手写(或 agent 写)的层
│   └── <id>.ts
├── bundles/<id>/           课包:自包含目录,iPad 整目录下载
│   ├── scene.json          派生:build 幂等再生
│   ├── manifest.json       派生:build 幂等再生
│   ├── audio/              TTS 预合成:派生但贵(由缓存回填,见下)
│   └── review.json         ★ 不可再生:家长验收记录
├── snaps/<id>/             纯缓存:keyframe 截图 + index.json,随时可删,snap 再生
└── .drawtell/              机器缓存预留位,整个目录可删(当前为空)
```

## 状态分类(规划的主轴:丢了怎么办)

| 类别 | 例子 | 丢了怎样 | git |
|---|---|---|---|
| 源 | `scenes/*.ts` | 不可再生 | ✓ |
| 人的决定 | `bundles/*/review.json` | 不可再生(验收是人做的) | ✓ |
| 贵派生 | `bundles/*/audio/`(+ 语音 CLI 的用户级缓存) | 可再生,但花钱耗时 | ✗ |
| 廉派生 | `bundles/*/{scene,manifest}.json`、`snaps/` | 秒级再生 | ✗ |

判断一个新文件放哪,先问它属于哪一类。

## 幂等与新鲜度

- **build 只写 scene.json / manifest.json**,不碰 review.json 与 audio/ ——
  重建永远不会误删人的决定和贵产物(现有实现已如此)。
- **产物文件里不放时间戳**:幂等 = 同输入字节一致;builtAt 之类易变元数据不进课包。
- **验收绑内容而不是绑目录**:review.json 记 `manifestHash`(+ sceneHash);
  场景改了重新 build,hash 对不上 = 验收自动失效,`ls` 应显示"已改动,需重验"。
  review.json 由家长验收动作写入(将来 serve 的验收页,或手工),CLI 的 build/snap 不生成它。
- snaps 新鲜度同理:index.json 里加 manifestHash(待实现),不符即过期。

## TTS 音频(预留,语音 CLI 落地时启用)

- 合成与内容寻址缓存归**独立的语音 CLI**(用户级 `~/.cache/`,跨工作区共享;
  设计见 growth-apps《架构重新设计.md》语音组件一节)。
- drawtell 侧只做粘合:manifest 各步 line → 语音 CLI batch → 拷进课包 `audio/` → 回填 audioSrc。
- 课包必须自包含(iPad 整目录下载、离线播放),所以 audio/ 是**缓存回填的拷贝**,不是引用。
- 改一句讲稿只重合成那一句——缓存 key 按步的文本算,不按整包算。

## 边界(不归工作区管的)

- `dist/web`、`public/fonts`:工具侧构建产物。
- 孩子的墨迹/录音上传:采集侧(kid-canvas / apps/canvas / lan-server)的数据,不进 drawtell 工作区。
- 错题状态机(错→讲过→隔日对→结清):家长通道 pipeline 的状态,在其自己的数据层,
  课包目录只被它引用,不反向存它的状态。

## 待办(按需落地,不急)

1. 工作区场景的类型引用:外部工作区里 `import type ... from '../src/player'` 路径不成立
   (运行时无碍——type import 会被擦除;影响的是编辑器与 tsc)。
   方案:drawtell 包加 `exports` 暴露类型,工作区 `import type { ChalkScene } from 'drawtell'`。
2. `drawtell ls`:每个场景一行,四态一眼看全——源(mtime)→ 课包(hash 是否新鲜)→
   截图(是否过期)→ 验收(有效/失效/未验)。
3. snaps/index.json 记 manifestHash;review.json 的写入入口(serve 验收页)。
