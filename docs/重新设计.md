# 重新设计

> 2026-10-07 起。起因:cotutor 的小课堂(做好的课,孩子从头看完、能拖、能停下来圈)把 drawtell 用到了接力式播放之外,碰出一串问题。拍板在文末。

## 碰到的事

| 碰到的事 | 根子在哪 |
|---|---|
| 小课堂要拖到任意一刻,`ChalkPlayer` 做不到;cotutor 照抄了一份 `timeline.ts` 自己算时钟 | 时间不是一等公民;包只导出带 React 的播放器 |
| iPad 上没点开始画面就自己画(Safari 放进页面后 SMIL 时间轴重新走) | 动画靠 SMIL,各浏览器不一样 |
| 圈的卡的缩略图要在页面里克隆 SVG、装看不见的 iframe 要 | 「某一刻的画面」只能在浏览器里算 |
| 圈住了什么只能估文字宽 | 字宽只在浏览器里量,课包不存 |
| 只能说「第 1 步画的 3 条线」,说不出「散的 3 根小棒」 | 元素只有 id 与几何,没有语义 |
| 「分一分」要读题(照片上圈字)→ 新画布 → 小刀切,做成了两个课包,刀不动 | 一个场景一块画板;只能加,不能移动、变形 |
| 横线擦掉再画回来,靠 `customData.tool: 'eraser'` 加画两遍 | 没有擦除、强调这类对已有元素的操作 |
| 一道题 151 行 TS,坐标全手算;家长真正在改的是 `.md` 讲法稿 | 创作源是「画法」,不是「讲法」 |
| 「数 1、2、3」只能大概对上声音 | 声音与笔画只在步这一级对齐 |
| `drawtell.json` 里有孩子、照片、收件箱,还有写 Obsidian 的 `note` | 家庭应用的事漏进了引擎 |

## 思路

1. **时间是主轴,步只是记号**。一堂课是一条时间线,任何一刻都能问画面是什么;接力式(到步停一下)是播放器的策略。
2. **纯核心**:时钟、某一刻的画面、几何、命中检测不碰 DOM、不带 React,服务端与 CLI 都能用(`drawtell/core`)。
3. **手绘在 build 时烤好**:带种子的手绘路径存进课包,播放按 t 算描边进度,不用运行时的 excalidraw 与 SMIL;excalidraw 只留作编辑器的导入导出。
4. **元素带语义,画板能变**:名字与分组;擦掉、移动、强调、淡出;一堂课里换画板。
5. **讲法稿是创作源**:`.md` 讲法稿 + 版式积木(点阵、成排、标签挨着谁)编译成场景,TS 是逃生口。
6. **声音对齐到词**:讲稿里写锚点,笔画落在说到那个词的时候(要 voxtell 给词级时间戳)。
7. **边界**:drawtell 管课包格式、编译、渲染与核心计算;家庭的角色、日记、孩子端标题归应用。

## 先后

1. **纯核心**(`drawtell/core`):`lessonClock` / `clockAt` / `frameAt`、`circleHits` / `describeCircle`。
2. **量好的几何、元素的名字**:字宽表(`scripts/gen-text-metrics.mjs` 用真播放器量)、`build` 落 `bounds`;场景的 `groups` 与元素的 `label`。
3. 擦掉、移动、强调、多块画板。
4. 去掉运行时的 excalidraw 与 SMIL,换成烤好的路径 + 按 t 渲染。
5. 讲法稿 + 版式积木。

## 拍板记录

**2026-10-07**:

1. **纯计算单独一个出口 `drawtell/core`**,不进 `drawtell/player`。理由:player 带 React,服务端 import 不了;核心不该跟着播放器的依赖走。时间线(`timeline.ts`)暂时留在 player 目录、由 core 转出,第 4 步换渲染时再挪。
2. **字宽表用真播放器量,不读字体文件**:一个字连写 10 遍、字号 100,临时 build、起 serve、playwright 读 `<g>` 的 rotate 中心。理由:和孩子看到的同一个渲染器;Xiaolai 拆成 209 个子集文件,读字体反而麻烦。汉字量出来全是 1 个字号宽。
3. **`groups` 与 `bounds` 放 scene.json,命中块照旧在 manifest.json**:分组是画面的一部分;manifest 管怎么播、怎么交互。
4. **名字只是语义**:不改画法、不改笔顺;一个元素可以在几组里。圈住一组的大半就说组名,圈得更满的组先认,一样满先认小的。
